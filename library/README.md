# Библиотека навыков

Большая коллекция навыков, которые **не** загружаются в контекст автоматически.
Claude находит нужный навык через активный навык `.claude/skills/skill-library`.

```
.claude/skills/skill-library/   ← единственный (или почти) активный навык
library/
  INDEX.md                      ← индекс: имя | коллекция | путь | описание
  build_index.py                ← пересборка индекса
  collections/
    ecc/                        ← affaan-m/ECC (MIT, см. ecc/LICENSE-ECC)
    <ваша-коллекция>/           ← сюда добавляйте свои
```

## Добавить свои навыки

1. Скопируйте папки навыков (каждая с `SKILL.md`) в `library/collections/<имя>/`.
2. `python3 library/build_index.py`
3. Закоммитьте.

## Сделать навык «всегда активным»

Скопируйте его папку в `.claude/skills/`. Держите активных навыков немного —
описание каждого занимает контекст в каждой сессии.

## Как вызвать

Просто опишите задачу — Claude проверит библиотеку. Или явно:
«возьми из библиотеки навык django-tdd».
