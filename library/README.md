# Библиотека навыков

Около 850 навыков из 7 коллекций плюс ваши собственные. Они **не** загружаются
в контекст автоматически: Claude находит нужный навык через библиотекаря
`.claude/skills/skill-library` — по индексу `INDEX.md`, по запросу на русском.

Просмотреть всё глазами: **[CATALOG.md](CATALOG.md)**.

```
.claude/skills/
  skill-library/          ← библиотекарь (всегда активен)
  <избранные>             ← копируются сюда из favorites.yaml
library/
  sources.yaml            ← реестр коллекций: репозиторий, лицензия, что брать
  sources.lock.json       ← на каком коммите каждая коллекция (генерируется)
  favorites.yaml          ← избранные навыки
  INDEX.md                ← индекс для библиотекаря (генерируется)
  CATALOG.md              ← каталог для вас (генерируется)
  tools/library.py        ← sync / index
  collections/
    ecc/ claude-skills/ marketing/ pm-skills/ pm-setup/ career/ academic/
    my/                   ← ВАШИ навыки — синхронизация их не трогает
```

## Как пользоваться

Просто опишите задачу — Claude проверит библиотеку и скажет, каким навыком
пользуется. Или явно: «найди в библиотеке навык для резюме», «возьми
marketing/copywriting», «какие есть навыки по SEO?».

## Обслуживание

| Что нужно | Команда / действие |
|---|---|
| Обновить все коллекции | `python3 library/tools/library.py sync` |
| Обновить одну | `python3 library/tools/library.py sync marketing` |
| Добавить коллекцию с GitHub | запись в `sources.yaml` → `sync <id>` |
| Добавить свой навык | папка `collections/my/<имя>/SKILL.md` → `index` |
| Сделать навык всегда активным | строка в `favorites.yaml` → `index` |

Или просто попросите Claude: «добавь коллекцию github.com/…», «сделай навык X
избранным», «обнови библиотеку».

**Автообновление:** каждый понедельник GitHub Actions
(`.github/workflows/library-sync.yml`) проверяет исходные репозитории и, если
есть изменения, открывает pull request. Запустить вручную: вкладка Actions →
Library sync → Run workflow.

**Не правьте навыки внутри синхронизируемых коллекций** — при обновлении
изменения пропадут. Скопируйте навык в `collections/my/` и меняйте там.

## Лицензии

| Коллекция | Лицензия |
|---|---|
| ecc, claude-skills, marketing, pm-setup, career | MIT — можно всё, сохраняя файл лицензии |
| pm-skills | CC BY-NC-SA 4.0 — только некоммерческое использование |
| academic | CC BY-NC 4.0 — только некоммерческое использование |

Файлы лицензий лежат в папке каждой коллекции. NC-коллекции подходят для
личных проектов; для платной работы их не используйте.
