# Мои навыки

Сюда кладите собственные навыки и изменённые копии чужих. Синхронизация эту
папку никогда не трогает.

Каждый навык — папка с файлом `SKILL.md`:

```markdown
---
name: my-skill-name
description: Что делает навык и когда его использовать (лучше по-английски —
  по описанию библиотекарь его находит; можно добавить русские ключевые слова).
---

# Инструкции

...
```

После добавления: `python3 library/tools/library.py index` и коммит.
