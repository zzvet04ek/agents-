# Проверка чертежей и GD&T

Навык Codex для проверки размеров, баз, геометрических допусков и оформления механических чертежей. Выдаёт таблицу замечаний с критичностью, расположением и предложением исправления.

## Запуск в Codex

Откройте репозиторий в новой сессии Codex и вызовите:

```text
$drawing-gdt-review Проверь чертёж drawings/part.pdf. Укажи стандарт, лист и зону каждого замечания, критичность и способ исправления. Если стандарт или назначение детали неизвестны, уточни их.
```

Передайте доступный Codex PDF, изображение или DXF. Навык установлен в стандартном проектном каталоге .agents/skills/ и не требует изменения глобальной конфигурации.

## Зависимости

Для изображений достаточно инструмента просмотра изображений в используемой среде Codex.

- PDF: утилита pdftoppm из Poppler; команда из исходника создаёт PNG рядом с выбранным префиксом вывода. Используйте отдельный рабочий каталог и кавычки для путей с пробелами.
- DXF: Python и пакет ezdxf для чтения геометрических объектов.
- Нумерованные пометки на PNG: Python и Pillow (модуль PIL), только если требуется такая разметка.
- ASME Y14.5 / ISO GPS: нужна применимая редакция стандарта и инженерный контекст. Текст навыка не заменяет стандарт; обобщённые правила чек-листа требуют проверки применимости к конкретному допуску и стандарту.
- Пункт 6 исходного SKILL.md ссылается на таблицы соседнего dfm-review. Этот навык не включён в поставку. Если таблицы недоступны, запросите данные о процессе и допустимых отклонениях; не выдавайте предполагаемые пределы за подтверждённые.

Автоматической установки зависимостей, сетевых запросов, удаления файлов, команд с повышением привилегий или доступа к секретам в поставляемых файлах нет. Пакеты не устанавливаются при загрузке навыка. Проверка исходного текста не является гарантией инженерной корректности выводов.

## Проверка установки

Проверены YAML-метаданные name/description, стандартный путь Codex и наличие относительного справочника. В среде подготовки pdftoppm, ezdxf и Pillow доступны. Опасных команд при статической проверке двух исходных Markdown-файлов не найдено. Проверка skills/list через Codex CLI в этой среде заблокирована ошибкой Read-only file system; после открытия ветки в новой рабочей сессии проверьте наличие навыка в меню /skills.
