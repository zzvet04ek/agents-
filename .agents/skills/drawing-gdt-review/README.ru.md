# Проверка чертежей и GD&T

Локально адаптированный навык Codex для проверки PDF, изображений и DXF. Проверяет размеры, базы, допуски, оформление и контролепригодность; разделяет подтверждённые ошибки, вопросы и рекомендации.

## Источник и изменения
Основан на https://github.com/BaratiLab/mechanical-engineering-skills/tree/119b1a946e2ea43784f5d045057b59757a1a7dd1/skills/drawing-gdt-review .
Лицензия MIT, copyright сохранён в LICENSE.
SKILL.md и checklist.md адаптированы: устранены категоричные обобщения GD&T, добавлены правила неопределённости, проверки нормативных оснований, отдельный режим ГОСТ/ЕСКД и учебные случаи. Это изменённая локальная версия; не заменяйте её автоматически upstream-копией.

## Запуск
Откройте проект в новой сессии Codex:
```text
$drawing-gdt-review Проверь drawings/part.pdf. Уточни нормативную систему и редакции, раздели ошибки, вопросы и рекомендации. Укажи лист/вид/зону и основания выводов.
```

Для ЕСКД:
```text
$drawing-gdt-review Проверь чертёж по ГОСТ/ЕСКД. Сначала предложи применимый перечень стандартов и запроси подтверждение редакций. Не переноси правила ASME автоматически.
```

## Зависимости и ограничения
- PDF: Poppler/pdftoppm; изображения: доступный просмотрщик.
- DXF: Python/ezdxf, при необходимости визуализация. Неподдерживаемые сущности явно исключаются из охвата.
- Разметка копии PNG: Pillow, только по запросу.
- dfm-review необязателен. Без его таблиц и данных процесса технологичность остаётся открытым вопросом.
- Нормативные тексты не включены; нужны применимые редакции и инженерный контекст. Навык не выдаёт сертификат соответствия.
- Скриптов установки нет; зависимости не устанавливаются автоматически. Команда pdftoppm пишет изображения в отдельный каталог; исходник сохраняется.
- Стандартный путь Codex: .agents/skills/drawing-gdt-review/. Загрузка через skills/list ранее не была подтверждена из-за Read-only file system в среде CLI; проверка структуры этого не заменяет.
