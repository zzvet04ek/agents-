# Учебные проверки инструкции

Это текстовые контрольные случаи, а не результаты автоматического распознавания PDF и не сертификация соответствия стандартам. При прогоне фиксируй фактический ответ отдельно от ожидаемого.

| ID | Вход | Ожидаемое поведение |
|---|---|---|
| T1 | Чётко заданный Ø6 ±0,1; позиционный допуск; расположение задано теоретически точными размерами | Не объявлять допуск диаметра конфликтом с позиционным |
| T2 | Есть только символ третьего угла, нормативная ссылка отсутствует | Уточнить стандарт; отдельно определить метод проецирования |
| T3 | Модификатор на скане нечитаем | Не угадывать; запросить фрагмент; оставить вопрос вне счётчика ошибок |
| T4 | Рамка ссылается на C; по всем листам и примечаниям база C не определена | Подтверждённая проблема базирования со ссылкой на наблюдаемые данные и исправлением |
| T5 | Допуск формы численно больше допуска размера, система и модификаторы неизвестны | Не объявлять универсальное нарушение; уточнить условия |
| T6 | Символ соосности; чертёж по ISO, редакция неизвестна | Не переносить запрет ASME 2018; запросить применимые источники |
| T7 | Задан допуск 0,005 мм; процесс неизвестен, dfm-review недоступен | Не утверждать недостижимость; запросить процесс, материал и размер |
| T8 | Запрошена проверка по ГОСТ без перечня редакций | Предложить список из standards.md; выполнить только общие проверки до подтверждения |
| T9 | Порядок баз C-A-B функционально задан | Не требовать алфавитного порядка или совпадения с хронологией сборки |
| T10 | Все листы читаемы, противоречий нет, но текст стандарта недоступен | Не заявлять полное нормативное соответствие; перечислить непроверенные требования |

Приёмка: ни одного выдуманного знака или нормативного пункта; вопросы не подсчитаны как ошибки; каждое подтверждённое замечание локализовано; исправления не назначают произвольные значения допусков.
