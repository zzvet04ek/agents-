# Product Manager v.1

Управляющий агент для продуктовых проектов. Технический ID: `product-manager-v1`; версия профиля: `1.1.0`.

## Запуск

В Codex откройте этот репозиторий и поставьте задачу:

> Используй Product Manager v.1. Проект: <project-id>. Прочитай профиль, восстанови доступное состояние и выполни следующую задачу.

Корневой AGENTS.md маршрутизирует запрос к [профилю](AGENTS.md). В Claude Code доступно определение `.claude/agents/product-manager-v1.md`; его можно явно выбрать как агента. Отображение названия в интерфейсе зависит от среды.

Это файловый профиль и протокол работы, а не запущенный сервер, фоновый процесс или выданные корпоративные полномочия. Новая сессия восстанавливает состояние из файлов и доступных источников. Внешние сервисы требуют подключённых инструментов; профиль не выдаёт доступ к Drive/GitHub.

## Навыки: 1 обязательный + 5 основных + 3 по задаче

| Режим | Навык | Назначение |
|---|---|---|
| Обязательный | my/skill-sufficiency | Проверка полноты запроса, достаточности навыков и необходимости дополнений |
| Основной | claude-skills/senior-pm | План, сроки, ресурсы, риски проекта, ответственность |
| Основной | claude-skills/product-manager-toolkit | Потребность, требования, приоритеты, продуктовые артефакты |
| Основной | claude-skills/product-strategist | Цели, стратегия, дорожная карта, портфель |
| Основной | claude-skills/process-mapper | Процессы, стадии, передачи, исключения |
| Основной | claude-skills/team-communications | Статусы, протоколы, коммуникационные материалы |
| По задаче | claude-skills/cto-advisor | Технические решения; аппаратную часть проверяют инженеры |
| По задаче | claude-skills/quality-manager-qms-iso13485 | СМК и управление разработкой медицинских изделий |
| По задаче | claude-skills/risk-management-specialist | Риски безопасности МИ; отдельно от рисков проекта |

«Основной» означает закреплённую компетенцию, а не загрузку всех инструкций на каждом ходе. Читать 1–3 подходящих навыка на задачу; до 5 при обоснованной необходимости. Применимость и ограничения — в [skills.json](skills.json). Навыки не копируются из синхронизируемых коллекций, поэтому их относительные ссылки сохраняются. Восемь исходных навыков указаны в индексе с MIT; новый собственный навык находится в library/collections/my/. Источники и библиотеки лицензий сохраняются.

Новые навыки добавляются в skills.json с причиной, триггером и ограничением; изменение фиксируется в CHANGELOG.md. Если нет подходящего — искать через библиотекаря. Наличие навыка не заменяет нормативный первоисточник и не создаёт инструмент.

## Что агент поддерживает

Для каждого проекта: README, STATE, TASKS, DECISIONS, ARTIFACTS, RISKS, PRECEDENTS и CHANGELOG.
Документы создаёт по задаче; утверждения отделяет от предложений. Прецедент включает контекст, основание решения и пределы повторного применения.

Правила: [AGENTS.md](AGENTS.md). Шаблоны: [templates](templates/).

## Подключение проекта

Назовите проект и согласованное место его данных. При первом запуске создайте `projects/<project-id>/` в разрешённом рабочем пространстве с STATE.md, TASKS.md, DECISIONS.md, ARTIFACTS.md, RISKS.md, PRECEDENTS.md и CHANGELOG.md по шаблонам. Файлы текущих частных проектов не входят в публичный профиль. Перед публикацией их содержания или ссылок проверьте явное разрешение на целевую аудиторию.
